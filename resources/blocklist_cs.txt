# Czech crossword blocklist
#
# Entries that must never reach a grid, in either tier. One word per line,
# lowercase, NFC, diacritics preserved. `#` starts a comment. Blank lines ignored.
#
# Applied in three places, all with the same file:
#   scripts/czech_standard_dict.py   --denylist   (Standard tier, at build time)
#   scripts/metropolitan_theme_dict.py --denylist (Preferred tier, at build time)
#   scripts/apply_blocklist.py                    (already-built .dict of either tier)
#
# The Standard-tier builder also denies any word whose morphological lemma is
# listed here, so `kamp` covers `kampu`, `kampem`, `kampy`.
#
# Rule of thumb for adding an entry: if no honest clue exists for it under
# CLUES.md § 12, or the publication would refuse the word on register grounds,
# it is a fill defect — and defects belong in the dictionary, not in the clue box.
